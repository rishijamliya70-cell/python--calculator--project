# 🧮 Python Calculator - BCA 1st Sem Project

> My First Python Project | Created by Rishi - BCA 1st Year

### 📝 About The Project
This is a simple command-line calculator made using Python as part of my BCA 1st Semester learning. The goal was to understand basic Python concepts like input, conditions and functions.

### ✨ Features
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division (with Zero Division Error Handling)
- Clean and Beginner Friendly Code

### 💻 How to Run This Code
1. Download the file `first.py`
2. Run in terminal:
   python first.py

### 🧠 What I Learned From This Project
- How to take user input in Python
- Using if-else conditions
- Writing clean code
- Handling errors (like division by zero)
- Using Git & GitHub for the first time!
